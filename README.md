# H-QLD: Hierarchical Quantitative–Linguistic Difficulty Model

This repository contains the **reproducible Python implementation**, **simulation data**, and **figures** supporting the article:

> Sorouhesh, M. R. (2025). *From Rasch to H-QLD: Rethinking GRE Item Difficulty for Non-Native Test Takers.* Manuscript submitted for publication.

---

## Overview
The H-QLD model introduces a **non-compensatory, hierarchical framework** for analyzing test-item difficulty in language-mediated assessments.  
It models the **lexical (l₂)**, **syntactic (l₁)**, and **logical (l₃)** components of cognitive processing as a sequential chain, inspired by order theory and partial-order lattices.  

Unlike Rasch or compensatory IRT models, H-QLD captures the *weakest-link principle*, identifying specific cognitive bottlenecks such as lexical overload or syntactic complexity.
